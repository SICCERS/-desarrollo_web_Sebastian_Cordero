Se decidio por una logica lineal para la aplicacion, donde se comienza con un inicio simple que obliga a ingresar a la pagina de registro de cada miembro
para luego se que se validen los resultados, se induce al registro de actividades, donde se planteo la idea de que si una person hace una misma actividad
más de una vez a la semana esta sea en los mismos horarios, se tomo esta decision por simplicidad. Luego del registro de la actividad se direccione a la tabla de miembros. sin embargo en cada pagina se tiene al aopcion de 
navergar por cualquier pagina relacionda con la aplicación

Respecto a las validaciones del numero de documetno giro esta decion entorno a los largos estandares de un rut que puedern ser de estructura como la siguiente xx.xxx.xx.x o x.xxx.xxx.x  y dado que al buscar info los numero sde pasaporte tambien giran 
a largos similares, pero sin conciderar las puntuaciones y guiones

Respecto a la decion del largo minimo de un nombre, se busco los nombres mas cortos existentes y se llego a un minimo de 3 letras, y el maximo la decisin se tomo conciderando que la intruccion es ingresar dos nombres

por otro lado respecto a la validacon del correo se estalecio una estructura estandar de un correo usario@.textosinespacios.texto y que no sea vacio

para validar que un input no sea vacio se uso .submit y se valida con qye el valor sea distinto de vacio, con esta combinacion nos permite que no se ingresen solo espacios o que simplemente este vacio el input

Respecto al diseño de la pagina se opto por usar el azul estandares de la universidad y una distribucion simple y similar para caada pagina 

Se tomo la decision de recolectar datos generales de identificacion para todo tipo de miembros, con el foco en dato del rut como eje 
principal de identificación de cada miembro, por si a futuro se necesesitaria establecer una base de datos,  esto es dado que este es unico.. El resto de datos bordan información de contacto generales como lo son el telefo y correo electronico,
odaemas de datos mas estandares como nombres apellidos y fecha de nacimiento.
